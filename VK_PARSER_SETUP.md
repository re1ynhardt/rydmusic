# VK (ВКонтакте) Music Parser

Парсер для получения музыки из ВКонтакте. **Работает БЕЗ access token!**

Парсит веб-страницы ВК напрямую, извлекая данные о треках из HTML и JavaScript. Позволяет искать треки и получать популярные аудиозаписи.

## Требования

**Никаких требований!** VK парсер работает без авторизации и access token.

## Как это работает?

Вместо использования API, парсер:
1. Загружает веб-страницу поиска/популярных треков ВК
2. Извлекает JSON данные о треках из HTML
3. Парсит данные и преобразует в формат приложения
4. Возвращает готовые к воспроизведению треки

## Использование

Просто используйте приложение — VK парсер автоматически включен!

```bash
flutter run
```

Никаких дополнительных конфигураций не требуется.

## Функциональность

### Поиск треков

```dart
final vkService = VkService();
final tracks = await vkService.search('Imagine Dragons', limit: 25);
```

Параметры:
- `query` — строка поиска
- `limit` — количество результатов (по умолчанию 25)
- `offset` — смещение для постраничной выборки

### Популярные треки

```dart
final popularTracks = await vkService.trending(limit: 25);
```

## Ограничения

- **Парсинг HTML**: Может сломаться если ВК изменит структуру страницы
- **Скорость**: Медленнее API (нужно парсить HTML)
- **Обложки**: Не все треки имеют обложку
- **Region**: Некоторые треки могут быть недоступны в зависимости от региона

## Обработка ошибок

Сервис автоматически обрабатывает ошибки:

- Проблема с парсингом → возвращает пустой список
- Сетевая ошибка → возвращает пустой список
- Отсутствие данных → возвращает пустой список

Все ошибки логируются в консоль для отладки.

## Интеграция с приложением

VK сервис автоматически инициализируется в [lib/main.dart](lib/main.dart):

```dart
MusicSourceType.vk: VkService(),
```

Сервис всегда включен и готов к использованию.

- **Now Playing Screen**: Отображает "VK" как источник при воспроизведении
- **Search/Trending**: Автоматически использует VK сервис
